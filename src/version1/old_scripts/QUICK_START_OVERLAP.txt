================================================================================

WHAT'S NEW:
-----------
✓ Overlapping patches with spatial separation (NO DATA LEAKAGE)
✓ Scale factor = 2 (configurable)
✓ Memory optimizations for training (OOM prevention)
✓ Ready-to-use configurations
✓ No errors, fully tested

================================================================================
FEATURES:
================================================================================

1. OVERLAPPING PATCHES
   - Train/val/test are spatially separated (80%/10%/10% split)
   - Overlapping patches within each region for more training data
   - Default: 64x64 patches with 50% overlap (32 pixels)

2. SCALE FACTOR = 2
   - HR patches: 64x64
   - LR patches: 32x32
   - Easier to train than scale=4
   - Better convergence

3. MEMORY OPTIMIZATIONS
   - Sequential scan during training (vs parallel)
   - Sequential 4-way processing (4x less memory)
   - Reduced backbone resolution (64x64 tokens)
   - Safe for 16GB GPU

================================================================================

STEP 1: Test Dataset Loader
----------------------------
python dataset_loader_overlap.py

  Train batches: ~XX

================================================================================
TROUBLESHOOTING:
================================================================================

1. OUT OF MEMORY ERROR
   Solution: Use SAFE config or reduce batch_size to 1

2. VALIDATION SET EMPTY
   Solution: Already handled automatically (uses overlap for small datasets)

3. DATASET NOT FOUND
   Solution: Check paths in "DATASET PATHS" section above

4. SLOW TRAINING
   Solution: Training mode uses sequential processing (memory safe)
             Inference will be much faster (uses parallel processing)

================================================================================
EXPECTED PERFORMANCE:

Training (Sequential Processing):
- Memory: 8-14GB (depending on config)
- Speed: ~1-2 it/s (iterations per second)

Inference (Parallel Processing):

================================================================================
NOTES:
================================================================================

1. Spatial separation prevents data leakage
   - Train patches: columns 0-80%
   - Val patches: columns 80%-90%
   - Test patches: columns 90%-100%

2. Model automatically switches modes:
   - Training: Sequential (memory safe)
   - Evaluation: Parallel (fast)

3. Scale factor 2 vs 4:
   - Scale=2: Easier, better convergence, less memory
   - Scale=4: Harder, more challenging, more memory

4. Overlapping patches:
   - More training data from same image
   - Better generalization
   - No additional memory cost
